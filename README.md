# Skypro.Wallet

Веб-приложение для учёта личных расходов. Пользователь может войти или
зарегистрироваться, вести список расходов и анализировать траты за выбранный
период. Данные аккаунта и расходов обрабатываются через Skypro WebDev API.

## Что реализовано

- Регистрация и вход в аккаунт. При регистрации проверяются имя, адрес
  электронной почты и пароль; логин формируется из имени.
- Сохранение авторизованной сессии в `localStorage` и выход из аккаунта.
- Загрузка и отображение расходов из API.
- Добавление расхода с описанием, категорией, датой и суммой. Описание должно
  содержать не менее четырёх символов, сумма — быть положительным целым числом.
- Удаление расхода.
- Анализ расходов за выбранный диапазон дат: календарь, общая сумма и диаграмма
  распределения по категориям.
- Обработка ошибок загрузки и повторный запрос при сбое; при завершении сессии
  приложение возвращает пользователя на экран входа.
- Русские названия категорий и форматирование дат и сумм.

## Как проверить

1. Установите зависимости и запустите приложение (инструкции ниже).
2. Войдите в тестовый аккаунт API (`admin` / `admin`) либо зарегистрируйте
   аккаунт. Для регистрации заполните имя, адрес электронной почты и пароль.
3. На странице **«Мои расходы»** проверьте загрузку списка. Добавьте расход,
   указав описание от четырёх символов, одну из категорий, дату и положительную
   целую сумму. Убедитесь, что запись появилась в таблице.
4. Удалите созданную запись и проверьте, что она исчезла из таблицы.
5. Откройте **«Анализ расходов»**, выберите начало и конец периода в календаре.
   Проверьте обновление общей суммы и диаграммы по категориям.
6. Нажмите **«Выйти»** и проверьте возврат на страницу входа. После повторного
   входа проверьте сохранение сессии и загрузку данных.

При использовании общего тестового аккаунта не добавляйте личные данные и
удаляйте созданные для проверки расходы.

## Запуск и проверка сборки

Требуется Node.js и npm.

```sh
npm install
npm run dev
```

Для проверки production-сборки и lint:

```sh
npm run build
npm run lint
```

## API

Приложение использует `https://wedev-api.sky.pro/api`.

| Операция | Метод и адрес |
| --- | --- |
| Вход | `POST /user/login` |
| Регистрация | `POST /user` |
| Получение расходов | `GET /transactions?sortBy=date` |
| Добавление расхода | `POST /transactions` |
| Удаление расхода | `DELETE /transactions/{id}` |
| Получение расходов за период | `POST /transactions/period` |

Для запросов расходов используется токен авторизованного пользователя.
Транзакции хранятся на стороне API, токен и профиль пользователя — в
`localStorage` браузера.

## Основные файлы

- `src/App.jsx` — состояние приложения, авторизация и обработчики расходов.
- `src/api.js` — запросы к API и обработка ответов.
- `src/data.jsx` — категории, преобразование транзакций и форматирование.
- `src/pages/AuthPage.jsx` — экран входа.
- `src/pages/RegistrationPage.jsx` — экран регистрации.
- `src/pages/ExpensesPage.jsx` — список и форма расходов.
- `src/pages/AnalysisPage.jsx` — выбор периода и анализ расходов.
